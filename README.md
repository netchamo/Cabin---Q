# Cabin Q

EQ ברמת אולפן לטלפון: פרמטרי, דינמי ו-linear phase, עם קומפרסור באס, ספקטרום חי ושליטה במגע.

## התקנה

**אנדרואיד:** בטלפון, פותחים את הקישור ומתקינים:
https://github.com/netchamo/Cabin---Q/releases/download/latest/cabin-q.apk

בפעם הראשונה הטלפון יבקש לאשר התקנה מהדפדפן. כל בנייה חדשה מתקינה את עצמה מעל הקודמת, וההגדרות נשמרות.

**אייפון:** פותחים ב-Safari את https://netchamo.github.io/Cabin---Q/ ובוחרים "הוסף למסך הבית".

## מה עובד היום

| | אנדרואיד | אייפון |
|---|---|---|
| נגינת קבצים מהזיכרון דרך ה-EQ | ✓ | ✓ |
| EQ פרמטרי, דינמי, linear phase, קומפרסור | ✓ | ✓ |
| EQ על כל האפליקציות (System EQ) | ✓ עקומה סטטית | — אפל לא מאפשרת |

**System EQ באנדרואיד:** הכפתור בראש המסך מפעיל את ה-EQ על השמע של כל הטלפון. ההפעלה עובדת בשתי דרכים במקביל:
1. חיבור לערוץ הפלט הכללי של המכשיר, במכשירים שמאפשרים את זה.
2. חיבור לכל נגן שמודיע על עצמו, כמו Spotify, VLC ו-Poweramp.

שורת הסטטוס מראה איזו דרך פועלת. בשלב הזה העקומה הסטטית עוברת למערכת. ה-EQ הדינמי והקומפרסור עובדים על קבצים בתוך האפליקציה, והם השלב הבא במנוע המערכתי.

## מבנה

```
web/        הממשק (index.html) — משותף לאנדרואיד ולאייפון
android/    אפליקציית אנדרואיד: WebView + מנוע EQ מערכתי (DynamicsProcessing)
.github/    בנייה אוטומטית: APK לאנדרואיד ואתר לאייפון
```

**עדכונים:** כל שינוי בממשק (`web/`) מתפרסם לאתר, והאפליקציה באנדרואיד מורידה אותו לבד ברקע, בלי התקנה. APK חדש נבנה רק כשמשתנה החלק של אנדרואיד (`android/`) או כשהממשק צריך גרסת אנדרואיד חדשה יותר (`web/min-native.txt`). אם ממשק שהורד לא נטען כראוי, האפליקציה חוזרת לבד לממשק המובנה.
